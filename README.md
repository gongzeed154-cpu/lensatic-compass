# เข็มทิศเลนเซติก (Lensatic Compass Web App)

เว็บแอพจำลองเข็มทิศเลนเซติกบนมือถือ ใช้กล้องหลังเล็งที่หมาย อ่านทิศเป็นองศาและมิล

- **มุมมองเล็ง** (ยกมือถือตั้งฉาก): ฝาเล็งหน้า เส้นเล็ง และแว่นขยายอ่านสเกล (แดง = องศา, ดำ = มิล)
- **มุมมองหน้าปัด** (วางมือถือราบ): หน้าปัดมองจากด้านบน
- ล็อกทิศ, ตั้งเป้าหมาย, โหมดฝึก, เลือกแสดงองศา/มิล

## วิธีใช้
เปิดผ่านลิงก์ https เท่านั้น (กล้องและเซ็นเซอร์ใช้ไม่ได้เมื่อเปิดเป็นไฟล์ในเครื่อง)
แล้วกด "เริ่มใช้งาน" และอนุญาตกล้องกับเซ็นเซอร์การเคลื่อนไหว

`qr-maker.html` ใช้สร้างรูป QR จากลิงก์ของแอพ เปิดในคอมพิวเตอร์ได้เลย

> เข็มทิศมือถือคลาดเคลื่อนได้ ใช้เป็นเครื่องฝึกเสริม ควรเทียบกับเข็มทิศจริงก่อนใช้สอน
